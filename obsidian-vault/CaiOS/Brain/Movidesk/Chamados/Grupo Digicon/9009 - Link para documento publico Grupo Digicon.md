Em conversa com o Cristiano pelo WhatssApp, foi questionou sobre a liberação de um vídeo treinamento para o publico fora da plataforma.
Para que esse vídeo possa ser liberado ao público, é necessário que a permissão do documento esteja configurada como pública.
1 - Pesquisar o nome: Publico.
2 - Colocar a ação que o perfil irá realizar, neste caso "ACESSAR".
3 - Adicionar a liberação do perfil no documento.
4 - Salvar a edição.
Após liberar o acesso público do documento, abra-o no modo de edição. Nessa tela, será exibido o link de acesso — basta copiá-lo, pois é através dele que os usuários conseguirão visualizar o conteúdo. Caso queira gerar um QR Code, o próprio navegador Chrome oferece essa opção, como mostrado no print abaixo.
"Para gerar o QR Code, copie o link e cole na barra de endereços do Chrome. Após abrir o sistema, clique com o botão direito do mouse na tela e selecione a opção indicada para gerar o código.
1 - Colar o link na barra do Chrome
2 - Clicar com o botão direito na tela e clicar na opção "Criar Código "QR" para esta página.
Após realizar essa função essa janela ira abrir com o código para a visualização da página.
